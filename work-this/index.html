3. 저장 위치와 iCloud 동기화

근무 기록·태그·설정은 우선 기기 내부 SQLite 데이터베이스에 저장합니다.

iOS에서 iCloud 계정과 CloudKit을 사용할 수 있으면 앱은 해당 Apple 계정의 CloudKit private database를 이용해 자동으로 동기화합니다. 앱에는 별도의 동기화 켜기·끄기 스위치가 없습니다. 동기화 기능은 근무·태그·설정 데이터와 변경 식별 정보를 Apple iCloud에 전송하고, 같은 계정의 기기에서 변경 사항을 가져옵니다.

iCloud에 로그인하지 않았거나 연결할 수 없는 경우에도 기기에 기록할 수 있습니다. 연결이 복구되면 대기 중인 변경 사항을 동기화할 수 있습니다. Android는 기기 내부 SQLite를 사용합니다.

앱은 iCloud 사용자 기록 식별자를 사용하지만 Apple 계정의 비밀번호나 인증 코드를 직접 입력받거나 저장하지 않습니다. 운영자는 다른 사용자의 private database 내용을 CloudKit 개발자 콘솔에서 직접 조회하는 기능을 제공받지 않습니다. 사용자가 문의 과정에서 스스로 전달한 내용은 운영자가 볼 수 있습니다.

iCloud 저장 공간과 서비스 운영은 Apple이 관리합니다. Apple 서비스의 개인정보 처리에 관한 내용은 Apple 개인정보 처리방침에서 확인할 수 있습니다. workthis는 iCloud의 저장 국가나 모든 데이터에 대한 종단 간 암호화를 별도로 보장하지 않습니다.

4. 데이터 보관과 삭제

사용자가 저장한 기록과 설정은 기기 내부 및 동기화된 iCloud 저장소에 보관됩니다. 현재 앱에는 일정 기간 후 자동으로 기록을 만료시키는 기능이 없습니다.

앱에서 근무 기록이나 태그를 삭제하면 일반 조회 화면에서 제외되고, iCloud 연결 시 삭제 상태가 동기화됩니다. 현재 구현은 삭제 표시뿐 아니라 삭제된 항목의 원본 내용도 저장소에 유지하며, 이를 자동으로 완전히 지우는 기능은 없습니다. 따라서 화면에서 삭제한 것을 저장소에서의 완전한 파기로 설명하지 않습니다.

앱을 삭제하거나 iCloud 연결을 중단하는 것만으로 이미 동기화된 iCloud 데이터가 함께 지워진다고 보장하지 않습니다. 현재 버전에는 앱 안에서 모든 기기·iCloud 데이터를 한 번에 완전히 삭제하는 기능이 없습니다. 데이터 관리나 삭제에 관한 문의는 위 문의처로 접수할 수 있습니다. 운영자는 사용자 private database에 직접 접근해 대신 삭제할 수 없으므로 사용자가 직접 조치할 수 있는 방법을 안내합니다.

5. 사용자 선택과 권리 행사

사용자는 앱에서 기록을 열람·수정하고 화면에서 삭제할 수 있습니다. iCloud 동기화 없이 기기에 기록할 수 있으며, iOS의 Apple 계정 및 iCloud 설정에서 해당 서비스 이용 여부를 관리할 수 있습니다.

개인정보 처리에 관한 열람·정정·삭제·처리정지 요청이나 문의는 위 문의처로 연락할 수 있습니다. 앱 운영자가 보유하지 않는 기기 내부 데이터 및 사용자 iCloud 데이터는 사용자의 직접 조치가 필요할 수 있습니다. 문의 시 Apple 계정 비밀번호, 인증 코드 또는 불필요한 근무 상세 내역을 보내지 마세요.

6. 문의 시 전달하는 정보

사용자가 이메일로 문의하는 경우 운영자는 Gmail을 통해 회신 주소, 문의 내용 및 사용자가 첨부한 파일을 수신할 수 있습니다. 해당 정보는 문의 응대에 사용하며, 문의를 확인하고 처리를 완료한 후 문의 메일과 첨부파일을 삭제합니다.

7. 보호 조치와 방침 변경

앱은 iCloud 계정별로 저장 공간을 구분하고, 로컬 저장과 동기화 변경을 일관되게 처리하도록 구현되어 있습니다. 앱 자체의 별도 SQLite 암호화나 생체 인증 잠금 기능은 제공하지 않습니다. 기기의 화면 잠금과 Apple 계정 보안 설정도 함께 관리해주세요.

앱의 처리 항목·목적·저장 방식이 변경되면 이 방침과 시행일을 갱신하고 앱 내 개인정보 처리방침 경로 또는 공개 페이지를 통해 확인할 수 있도록 합니다.
